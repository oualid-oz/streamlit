# Les données du projet de vendredi

Huit cas, un dossier : les fichiers sont ici, dans `data/projets/`, donc déjà dans votre copie du dépôt. Rien à télécharger ailleurs. Un lien de fichier ci-dessous le télécharge seul, si besoin.

```python
import pandas as pd
df = pd.read_parquet("data/projets/energie.parquet")
```

Chaque cas a sa page dans [`projet/cas/`](../../projet/cas/README.md) : le contexte, qui utilise l'appli, la décision, chaque colonne expliquée, les pièges et des questions métier possibles. `summary.json` donne, pour chaque fichier, les colonnes, la période et une ligne réelle.

D'où vient chaque fichier, avec l'adresse exacte de chaque couche du Département du Loiret : [`sources/README.md`](../../sources/README.md), et les scripts qui les ont construits.

Les fichiers `.geojson` servent aux cartes Plotly sans geopandas : `px.choropleth_map(df, geojson=json.load(open(...)), locations="code_insee", ...)`. Les licences demandent de citer la source : mettez-la dans le pied de page de votre appli (« Source : RTE, éCO2mix », « Inside Airbnb »…). Olist est sous licence non commerciale : suffisant pour un cours, pas pour un produit.

Le cas 8 joint trois jeux du Département du Loiret sur data.gouv.fr : [population municipale](https://www.data.gouv.fr/datasets/population-municipale-des-communes-departements-du-loiret), [structures de santé](https://www.data.gouv.fr/datasets/structures-de-sante-departement-du-loiret) et [lieux de covoiturage](https://www.data.gouv.fr/datasets/lieux-de-covoiturage-organisation-departement-du-loiret). Les centres des communes viennent de [geo.api.gouv.fr](https://geo.api.gouv.fr).
